Authentication

All API endpoints require authentication. You can use:

  • Session Authentication: Use your browser session (works automatically when logged in). For cURL, include the session cookie.
  • Basic Authentication: Send username and password in the Authorization header
Authorization: Basic base64(username:password)

Example with Basic Auth:

curl -X GET "{{ base_url }}/api/tables/" \ -u "username:password"

API Token Authentication (Recommended)

API tokens are the recommended way to authenticate API requests. Create and manage your API tokens here.

Example with Token:
curl -X GET "{{ base_url }}/api/tables/" \ -H "Authorization: Token YOUR_TOKEN_HERE"
