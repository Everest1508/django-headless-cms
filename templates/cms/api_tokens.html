How to Use API Tokens

Include your API token in the Authorization header of your HTTP requests:

Authorization: Token YOUR_TOKEN_HERE

Example with cURL:

curl -X GET "{{ base_url }}/api/tables/" \ -H "Authorization: Token YOUR_TOKEN_HERE"
